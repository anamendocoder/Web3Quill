# Web3Quill

Turns personal finance data into standardized CSV files for small businesses and independent contractors.

The key benefits of using Web3Quill include:

- Turns personal finance data into
- standardized CSV files for small
- businesses and independent contractors

## Key Features

- Turns personal finance data into
- standardized CSV files for small
- businesses and independent contractors

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/Web3Quill.git`
2. `cd Web3Quill`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
